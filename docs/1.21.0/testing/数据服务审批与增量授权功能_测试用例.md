## 一、增量授权测试用例

### TC-E3-001：增量授权 - 首次提单无历史用户

**来源**：需求文档 - E3增量授权核心功能

**测试类型**：功能测试

**前置条件**：
- 存在API(ID=100, 版本ID=1001)
- 该API没有历史审批记录

**测试步骤**：
1. 用户首次提单并填写授权用户"user1,user2"
2. 审批通过后调用审批刷新接口
3. 查询生成的Token列表

**预期结果**：
- 为user1生成Token
- 为user2生成Token
- Token状态为有效
- 不执行历史用户合并

**测试数据**：
```json
{
  "approvalName": "增量授权首次提单无历史用户",
  "backgroundDesc": "test",
  "applyUser": "${user1},${user2}",
  "duration": "30",
  "importance": "3",
  "sensitive": "0",
  "attentionUser": "",
  "creator": "${submit_user}",
  "submitApiInfos": [
    {
      "apiId": $(apiId),
      "apiVersionId": $(apiVersionId)
    }
  ],
  "workspaceId": "${workspaceId}"
} 
```
测试执行步骤:
${} 是全局变量, $() 是要从接口获取的参数

#### 步骤1：查询可用API
```bash
GET /api/rest_j/v1/dss/apiservice/availableSubmitApi?workspaceId=${workspaceId}
```
```java
log.info("步骤1: 查询可用API - workspaceId={}, apiName={}", ${workspaceId}, ${test_case_first});
```

#### 步骤2：提交审批单
```bash
POST /api/rest_j/v1/dss/apiservice/submit
Request Body:
{
  "approvalName": "增量授权首次提单无历史用户",
  "backgroundDesc": "test",
  "applyUser": "${user1},${user2}",
  "duration": "30",
  "importance": "3",
  "sensitive": "0",
  "attentionUser": "",
  "creator": "${submit_user}",
  "submitApiInfos": [{"apiId": $(apiId), "apiVersionId": $(apiVersionId)}],
  "workspaceId": "${workspaceId}"
}
```
```java
log.info("步骤2: 提交审批单 - apiId={}, versionId={}", $(apiId), $(apiVersionId));
```

#### 步骤3：获取审批单号(authId)
```bash
GET /api/rest_j/v1/dss/apiservice/apiVersionQuery?serviceId=$(apiId)
```
从响应的 `result` 数组中提取对应版本的 `authId`：
```javascript
authId = response.data.result.find(v => v.id == $(apiVersionId)).authId
```
```java
log.info("步骤3: 获取审批单号 - apiId={}, versionId={}, authId={}", $(apiId), $(apiVersionId), ${authId});
```

#### 步骤4：等待手动审批
```java
log.info("============================================");
log.info("等待手动审批");
log.info("============================================");
log.info("请在DataMap审批系统中完成以下操作：");
log.info("  审批单号(authId): {}", ${authId});
log.info("  API版本ID: {}", $(apiVersionId));
log.info("  授权用户: {}, {}", ${user1}, ${user2});
log.info("============================================");
log.info("审批完成后，请继续执行后续步骤");
log.info("============================================");
```


#### 步骤5：调用审批刷新接口
```bash
GET /dss/apiservice/approvalRefresh?approvalNo=${authId}
```
```java
log.info("步骤6: 调用审批刷新接口 - approvalNo={}", ${authId});
```

#### 步骤6：验证Token生成
```bash
GET /dss/apiservice/tokenQuery?apiId=$(apiId)&currentPage=1&pageSize=100
```
```java
log.info("============================================");
log.info("验证首次提单结果");
log.info("============================================");
log.info("  查询Token列表 - versionId={}", $(apiVersionId));
log.info("  预期Token数量: 2");
log.info("  预期用户: {}, {}", ${user1}, ${user2});
log.info("============================================");
```
