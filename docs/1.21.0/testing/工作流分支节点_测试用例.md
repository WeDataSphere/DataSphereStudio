# 工作流分支节点测试用例

## 1. 文档信息
- 版本：1.20.0
- 范围：`workflow.branch` 节点最新方案
- 测试重点：节点属性规则、变量传递、下游调度控制

## 2. 测试范围
- 分支节点元数据与属性显示
- `branch.rules` 保存与回显
- 上游变量传递
- 默认规则与异常分支
- 下游节点 `scheduled/skipped` 控制

## 3. 前置条件
- 测试环境已部署最新分支节点实现
- 数据库已执行分支节点相关元数据 SQL
- 工作流编辑器可创建 `workflow.branch` 节点

## 4. 测试用例
### TC_001 分支节点可创建
- 前置条件：工作流编辑器已打开
- 步骤：
  1. 从节点面板拖入分支节点
- 预期结果：
  - 画布上成功创建 `workflow.branch`
  - 节点属性中存在 `branch.rules`

### TC_002 branch.rules 可保存并回显
- 步骤：
  1. 新建分支节点
  2. 配置两条直接出边
  3. 在属性中填写
     ```text
     amount>100=节点A
     default=节点B
     ```
  4. 保存工作流并重新打开
- 预期结果：
  - `branch.rules` 保存成功
  - 重新打开后规则文本不丢失

### TC_003 保存时校验至少两条出边
- 步骤：
  1. 新建分支节点
  2. 仅连接一个下游节点
  3. 填写任意 `branch.rules`
  4. 保存工作流
- 预期结果：
  - 保存失败
  - 错误信息提示分支节点至少需要两条出边

### TC_004 保存时校验规则必须引用直接下游节点
- 步骤：
  1. 分支节点连接 节点A、节点B
  2. 在 `branch.rules` 中填写
     ```text
     amount>100=节点X
     default=节点B
     ```
  3. 保存工作流
- 预期结果：
  - 保存失败
  - 错误信息提示规则引用了非直接下游节点

### TC_005 上游 SQL 输出变量可被分支节点读取
- 前置条件：上游 SQL 节点在分支节点之前执行
- 数据：
  ```sql
  select sum(price) as amount from order_info
  ```
- 分支规则：
  ```text
  amount>1000=大额处理
  default=普通处理
  ```
- 预期结果：
  - 分支节点成功读取变量 `amount`
  - 条件命中时执行 `大额处理`

### TC_006 上游映射变量可被分支节点读取
- 前置条件：上游节点配置 `branch.output.mapping=amount=total_amount`
- 数据：
  ```sql
  select sum(price) as total_amount from order_info
  ```
- 分支规则：
  ```text
  amount>1000=大额处理
  default=普通处理
  ```
- 预期结果：
  - 分支节点可读取映射后的 `amount`
  - 路由结果正确

### TC_007 默认规则生效
- 数据：
  - `amount=50`
- 分支规则：
  ```text
  amount>100=节点A
  amount<10=节点B
  default=节点C
  ```
- 预期结果：
  - 前两条规则均不命中
  - 选择 `节点C`

### TC_008 无命中且无默认规则时报错
- 数据：
  - `amount=50`
- 分支规则：
  ```text
  amount>100=节点A
  amount<10=节点B
  ```
- 预期结果：
  - 分支节点失败
  - 日志或错误信息包含无匹配规则

### TC_009 命中的下游节点进入 scheduled
- 数据：
  - `amount=150`
- 分支规则：
  ```text
  amount>100=节点A
  default=节点B
  ```
- 预期结果：
  - `节点A` 进入 `scheduled`
  - 最终执行

### TC_010 未命中的兄弟节点进入 skipped
- 数据：
  - `amount=150`
- 分支规则：
  ```text
  amount>100=节点A
  default=节点B
  ```
- 预期结果：
  - `节点B` 进入 `skipped`
  - 不会被实际执行

## 5. 回归点
- 不包含分支节点的现有工作流执行不受影响
- 普通 SQL/PySpark 节点执行结果提取不受影响
- 工作流保存与再次打开不受影响

## 6. 不再测试的旧方案内容
以下内容不属于当前版本，不应再作为测试范围：
- 分支边条件配置弹窗
- 边级 `condition / isDefault / priority`
- 独立分支配置表 CRUD
- 复杂逻辑表达式引擎
