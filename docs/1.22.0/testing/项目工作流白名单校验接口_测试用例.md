# 项目工作流白名单校验接口_测试用例

## 一、测试概述

### 1.1 测试目的
验证项目工作流白名单校验接口功能，确保：
- 接口能正确判断项目或工作流是否在白名单中
- 前端能根据接口返回结果动态控制复制按钮显隐
- 不影响现有白名单相关接口功能

### 1.2 测试范围
| 接口 | 路径 | 说明 |
|-----|------|------|
| checkIsWhite（新增） | /dss/framework/project/checkIsWhite | 白名单校验 |
| listNodeType | /dss/workflow/listNodeType | 回归验证 |
| copyProject | /dss/framework/project/copyProject | 回归验证 |
| copyOrchestrator | /dss/framework/orchestrator/copyOrchestrator | 回归验证 |

### 1.3 测试环境
- DSS版本：1.22.0-SNAPSHOT
- JDK版本：1.8
- 测试类型：接口测试 + 前端功能测试
