### TC-E1-001：批量提单 - 正常提单多个API

**来源**：需求文档 - E1批量提单功能

**测试类型**：功能测试

**前置条件**：
- 用户已登录系统
- 存在2个API版本处于"未提单"状态

**测试步骤**：
1. 访问批量提单页面
2. 选择两个API：订单查询API(ID=100, 版本ID=1001)、用户管理API(ID=101, 版本ID=1002)
3. 填写以下信息：
   - 审批单名称：API批量授权申请
   - 授权用户：user1,user2
   - 授权期限：30天
   - 工作空间ID：180
   - 背景描述：批量授权测试
4. 提交审批单

**预期结果**：
- 系统返回提单成功
- 每个API版本创建一条审批记录
- API版本状态更新为"已提单"
- 生成统一审批单号

**测试数据**：
```json
{
  "submitApiInfos": [
    {"apiId": 100, "apiVersionId": 1001},
    {"apiId": 101, "apiVersionId": 1002}
  ],
  "approvalName": "API批量授权申请",
  "applyUser": "user1,user2",
  "duration": "30",
  "workspaceId": 180,
  "backgroundDesc": "批量授权测试",
  "sensitive": 0
}
```

**优先级**：P0
**标签**：@smoke @critical

- 最终授权用户：user1,user2,user3,user4

**测试数据**：
