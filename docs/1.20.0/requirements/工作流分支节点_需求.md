# 工作流分支节点需求文档

## 1. 文档信息
- 版本：1.20.0
- 状态：已更新
- 适用范围：DSS 工作流 `workflow.branch` 节点

## 2. 背景
当前 DSS 工作流需要支持运行时条件分支，采用“分支节点属性驱动”的方案。

用户在分支节点属性中填写 `branch.rules`，运行时根据规则文本与上游传入变量决定唯一一个可执行下游节点，其余直接下游节点跳过执行。

## 3. 目标
新增一个分支节点类型 `workflow.branch`，满足以下目标：
- 用户可在工作流画布中拖入分支节点。
- 分支规则通过节点属性 `branch.rules` 配置。
- 分支节点执行时根据运行时变量判断唯一一个下游节点。
- 未被命中的兄弟下游节点自动跳过。
- 若无规则命中且未配置默认规则，则分支节点执行失败。

## 4. 规则模型
### 4.1 节点类型
- 节点类型：`workflow.branch`
- 节点职责：控制流路由节点，不提交 Linkis 作业

### 4.2 分支规则属性
分支规则统一写在节点属性 `branch.rules` 中，支持多行文本。

格式：
```text
条件=下游节点名
```

示例：
```text
amount>100=节点A
amount<10=节点B
default=节点C
```

说明：
- 等号左侧是条件。
- 等号右侧是分支节点的直接下游节点名称。
- `default`、`else`、`*` 视为默认规则。
- 规则按书写顺序匹配，命中第一条后停止。

### 4.3 支持的条件运算
当前版本支持：
- `==`
- `!=`
- `>`
- `<`
- `>=`
- `<=`

说明：
- 允许直接写 `amount>100`，也允许写 `${amount > 100}`。
- 不支持 `AND`、`OR`、`NOT` 等复杂逻辑表达式。
- 不支持在边上配置条件。

## 5. 变量来源
分支节点运行时从共享 `flow_var_map` 中读取变量。

### 5.1 工作流全局变量
工作流启动参数和流程属性会被注入 `flow_var_map`，可直接在规则中引用。

示例：
```text
run_date==2026-03-25=节点A
default=节点B
```

### 5.2 上游节点输出变量
上游普通节点成功后，执行结果中的变量会被回写到共享 `flow_var_map`，分支节点可直接读取。

当前版本支持的方式：
- SQL / PySpark 等节点产出结果集变量。
- 结果集列名可直接作为变量名使用。
- 也可通过 `branch.output.mapping` 做别名映射。

示例：
- 上游 SQL 输出列名为 `total_amount`
- 节点属性 `branch.output.mapping` 配置为 `amount=total_amount`
- 分支规则中即可写 `amount>100=节点A`

### 5.3 不支持的变量来源
当前版本不支持：
- 仅通过日志 `print(...)` 输出变量
- 复杂多结果集的自动映射
- 边级变量配置

## 6. 关键业务规则
- 分支节点至少需要两条直接出边。
- `branch.rules` 必填。
- `branch.rules` 中引用的下游节点名必须是该分支节点的直接下游节点。
- 若存在默认规则，默认规则在所有普通规则未命中时生效。
- 若不存在默认规则且没有任何规则命中，则分支节点失败。
- 分支节点只选择一个下游节点执行。
- 未命中的其他直接下游节点自动跳过。

## 7. 用户使用方式
### 7.1 配置步骤
1. 在工作流中拖入分支节点。
2. 从分支节点连出至少两条边到下游节点。
3. 打开分支节点属性面板。
4. 在 `branch.rules` 中填写规则。

示例：
```text
amount>100=大额处理
amount<=100=普通处理
```

### 7.2 上游 SQL 示例
SQL：
```sql
select sum(price) as amount from order_info
```

分支规则：
```text
amount>1000=大额处理
default=普通处理
```

### 7.3 上游 SQL 别名映射示例
SQL：
```sql
select sum(price) as total_amount from order_info
```

上游节点属性：
```text
branch.output.mapping = amount=total_amount
```

分支规则：
```text
amount>1000=大额处理
default=普通处理
```

## 8. 验收标准
- 能在节点面板中看到并拖入 `workflow.branch`。
- 节点属性中可配置 `branch.rules`。
- 上游变量能够被分支节点读取。
- 命中规则的下游节点会执行。
- 未命中的兄弟下游节点会跳过。
- 无匹配规则且无默认规则时，分支节点失败。

- 分支配置 CRUD API
- 边上可视化配置条件表达式
- 多分支并行命中
- 复杂逻辑表达式引擎
