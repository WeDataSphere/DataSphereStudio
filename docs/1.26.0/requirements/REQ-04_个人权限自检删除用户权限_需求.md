## 一、需求背景

根据 UM（统一权限管理系统）的全行权限检视结果，**5425|意书（DSS-IDE）子系统有 8 条用户角色授权需删除**，需在本系统（DSS）内完成用户权限删除整改。整改依据：ITSM 单 [12570114](https://itsm.weoa.com/itsm/web/index.html#/requestDetail/12570114)。

DSS 现有权限数据模型：`dss_workspace_user_role` 表（工作空间用户-角色授权关系），配套管理能力为 `DSSWorkspaceUserRestful`（`/clearUser` 全量清理、`/revokeUserRole` 定向回收，均以 HPMS_USER_TOKEN 鉴权）。

## 二、需求描述（澄清结论固化）

| # | 澄清项 | 结论（2026-11-13 用户确认） |
|---|--------|--------------------------|
| C-1 | 交付形态 | **SQL 脚本**：查询待删清单 + 事务化 DELETE + 删后核验，人工在库上执行 |
| C-2 | 删除范围 | 仅删除**角色下的用户授权**（dss_workspace_user_role 行级删除）；**不删除角色本身**（dss_workspace_role 不动） |
| C-3 | 自动化 | 不做 ITSM 审批后自动调 DSS 接口的自动化集成（现有接口已接入 ITSM/HPMS 鉴权码，集成复杂度高；如需自动化另立需求） |
| C-4 | 明细来源 | 8 条待删明细执行前由需求方从 UM 检视结果/ITSM 单提供，或按 UM 口径在 DSS 库自检定位 |

## 三、功能需求详情

### E1: 待删清单查询 `P0`

**描述**：提供只读查询 SQL，按用户名/工作空间/角色维度列出待删除的授权记录（8 条），执行删除前人工核对。

**验收标准**
- AC1.1: 查询 SQL 返回用户名、workspace_id、role_id、role 名称、授权时间等核对字段；
- AC1.2: 查询为只读（SELECT），不锁表不修改数据。

### E2: 事务化删除 `P0`

**描述**：提供事务化 DELETE SQL，精确删除 8 条用户角色授权记录；脚本参数化（用户名+workspace_id+role_id 三元组），不硬编码。

**验收标准**
- AC2.1: DELETE 以显式事务包裹（START TRANSACTION → DELETE → 核验 → COMMIT/ROLLBACK）；
- AC2.2: WHERE 条件为三元组精确匹配（用户名 + workspace_id + role_id），不使用宽泛条件；
- AC2.3: 删除行数与预期一致（8 条），数量不符时脚本提示回滚。

### E3: 删后核验 `P0`

**描述**：提供核验查询 SQL，确认目标记录已删除、误删保护（对比删除前后计数）。

**验收标准**
- AC3.1: 核验查询返回目标三元组 0 行；
- AC3.2: 删除前后对该批用户的剩余授权数对比输出。

## 四、边界定义

| ✅ 包含 | ❌ 不包含 |
|--------|----------|
| dss_workspace_user_role 行级授权删除（8 条） | 角色本身删除（dss_workspace_role） |
| 查询/删除/核验三段式 SQL 脚本 | ITSM 自动化集成（另立需求） |
| 执行说明与回滚指引 | 业务代码改动、接口变更 |
| | 用户主记录删除（dss_workspace_user，UM 未要求清用户，仅删角色授权） |

## 五、风险与回滚

| 风险 | 等级 | 缓解 |
|------|:---:|------|
| 删除范围过大（WHERE 不精确误删他人授权） | 高 | 三元组精确匹配 + 先查后删 + 事务核验 |
| 角色被误删（需求明确仅删用户授权） | 高 | 脚本不触碰 dss_workspace_role |
| 删除后用户失去唯一角色导致登录异常 | 中 | 执行前核验用户剩余角色数（E3.2）；如有唯一角色用户，需求方确认后执行 |
| 生产库直操作规范 | 中 | 走 DBA 工单流程执行，脚本仅作为工单附件 |

回滚：删除操作不可直接逆——执行前备份待删记录（SELECT ... INTO OUTFILE 或 INSERT INTO 备份表），误删时按备份 INSERT 还原。

## 六、测试关注点

1. 脚本语法在目标 MySQL 版本可执行（5.7/8.0 兼容）；
2. 三元组 WHERE 精确性（在 SIT 库用测试数据验证删除范围）；
3. 事务回滚路径（人为制造数量不符，验证 ROLLBACK）；
4. 删除后 DSS 页面权限表现（用户角色列表实时生效）。
