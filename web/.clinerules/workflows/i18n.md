# 国际化翻译处理工作流

根据用户需求处理指定页面或文件中未做国际化处理的部分，目标语言支持中文，英文。将中文文本替换为使用i18n的方式展示，并将语言配置放置在用户指定模块的i18n文件夹中。

## 参数

如果工作流需要参数，在此说明：
- {{MODULE_NAME}}: 指定的模块名称，如scriptis、workflows等
- {{FILE_PATH}}: 需要处理的文件路径

## 工作流执行的详细步骤

1. 用户指定需要处理的模块和文件路径
2. 检查指定模块的i18n文件夹是否存在，如`packages/{{MODULE_NAME}}/i18n/`
3. 扫描指定文件中的中文文本内容（代码注释除外，包括html注释，JavaScript注释等）
4. 为扫描到的中文文本生成唯一的键名
5. 将中文文本提取到对应的语言配置文件中（如zh.json、en.json）
6. 将文件中的中文文本替换为`$t('message.xxx.xxx')`格式的国际化调用
7. 保存修改后的文件
8. 更新语言配置文件，添加新的翻译条目

## 执行示例

```bash
# 处理scriptis模块中的result.vue文件
cline run i18n --module scriptis --file packages/shared/components/consoleComponent/result.vue

# 处理workflows模块中的module.vue文件
cline run i18n --module workflows --file packages/workflows/module/process/module.vue
```

## 常见操作命令

```xml
<!-- 读取Vue文件内容进行分析 -->
<read_file>
<path>packages/shared/components/consoleComponent/result.vue</path>
</read_file>

<!-- 读取现有i18n配置文件 -->
<read_file>
<path>packages/scriptis/i18n/common/zh.json</path>
</read_file>

<!-- 更新i18n配置文件 -->
<write_to_file>
<path>packages/scriptis/i18n/common/zh.json</path>
<content>
{
  "message": {
    "common": {
      "resulttip": "结果提示",
      "viewSet": "查看集合"
    }
  }
}
