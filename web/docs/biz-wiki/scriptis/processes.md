# Scriptis 脚本开发流程

## 脚本开发主流程

### 流程图

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  打开脚本  │───▶│  编辑脚本  │───▶│  执行脚本  │───▶│  查看结果  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
     │               │               │               │
     ▼               ▼               ▼               ▼
 ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐
 │新建/打开│    │语法高亮 │    │选择引擎 │    │结果集展示│
 └────────┘    │自动补全 │    │提交任务 │    │数据导出 │
               └────────┘    └────────┘    └────────┘
```

### 状态说明

| 状态 | 说明 | 进入条件 | 退出条件 |
|------|------|---------|---------|
| 新建 | 创建新脚本 | 用户点击"新建脚本" | 脚本创建成功 |
| 编辑 | 编辑脚本内容 | 脚本打开 | 用户执行或关闭 |
| 执行中 | 任务执行中 | 用户点击"执行" | 任务完成或取消 |
| 成功 | 任务执行成功 | 任务正常完成 | 用户查看结果 |
| 失败 | 任务执行失败 | 任务执行出错 | 用户处理错误 |
| 取消 | 任务被取消 | 用户点击"取消" | - |

## 脚本创建流程

### 步骤

1. **选择创建位置**
   - 在工作目录侧边栏选择目标目录
   - 或直接在工具栏点击"新建"

2. **填写脚本信息**
   - 脚本名称
   - 脚本类型（SQL、Python、Shell 等）
   - 存储路径

3. **脚本初始化**
   - 创建脚本文件
   - 初始化编辑器
   - 加载语法高亮

## UDF 管理流程

### 创建 UDF

```
新建 UDF ──▶ 选择类型 ──▶ 上传代码 ──▶ 注册函数
```

### UDF 类型

| 类型 | 说明 |
|------|------|
| UDF | 标量函数，一行输入一行输出 |

## 任务管理流程

### 任务状态流转

```
待执行 ──▶ 执行中 ──▶ 成功/失败/取消
```

### 任务操作

| 状态 | 可用操作 |
|------|---------|
| 待执行 | 编辑、删除、立即执行 |
| 执行中 | 取消、查看日志 |
| 成功 | 查看结果、重新执行 |
| 失败 | 查看日志、重新执行 |
| 取消 | 重新执行 |

## WebSocket 通信流程

### 连接建立

```javascript
// 初始化 WebSocket
socket = new Socket({
  url: `ws://${host}/ws/path`,
  errHandler: (error) => {
    // 错误处理，自动降级为 HTTP
  }
})

// 监听消息
socket.on('data', (data) => {
  // 处理推送数据
})
```

### 消息类型

| 类型 | 说明 | 处理方式 |
|------|------|---------|
| 日志推送 | 任务执行日志 | 追加到日志面板 |
| 进度更新 | 执行进度百分比 | 更新进度条 |
| 状态变更 | 任务状态变化 | 更新任务状态 |
| 结果推送 | 执行结果数据 | 渲染结果集 |

### 降级策略

当 WebSocket 连接失败时，自动降级为 HTTP 轮询：

1. 检测 WebSocket 连接失败
2. 切换到 HTTP 模式
3. 定时轮询获取状态
