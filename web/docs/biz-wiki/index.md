# 业务知识导航

## 业务领域概览

DataSphereStudio Web 是一个数据开发工作台，包含以下核心业务领域：

| 业务领域 | 说明 | 文档路径 |
|---------|------|---------|
| Scriptis | 脚本开发与交互式数据分析 | [biz-wiki/scriptis/](./scriptis/) |
| Workflow | 工作流可视化编排与管理 | [biz-wiki/workflow/](./workflow/) |

## 业务术语索引

详见 [领域词典](./glossary.md)。

## 各领域核心功能

### Scriptis（脚本开发）

- 多语言脚本编辑（SQL、PySpark、HiveQL）
- 任务提交与执行（Spark、Hive）
- 结果集展示与可视化
- 数据库管理
- UDF 与函数管理
- 资源管理

### Workflow（工作流）

- DAG 工作流可视化编排
- 工作流版本管理
- 流程实例监控
- 调度配置
- 发布管理
