# 通过 URL 展示结果集数据功能设计文档

## 1. 需求概述

### 1.1 需求背景
用户需要通过访问 URL 直接渲染展示对应的表格数据，URL 参数包含对应任务的 taskId。该功能用于内部使用，无需权限控制。

### 1.2 需求目标
- 支持通过 URL 参数直接访问和展示任务执行结果
- 保留表格右侧的工具栏功能
- 提供友好的错误提示
- 不影响现有功能

## 2. 功能设计

### 2.1 URL 参数设计

#### 2.1.1 参数说明

| 参数名 | 类型 | 必备性 | 说明 |
|--------|------|--------|------|
| taskId | String | 必备 | 任务唯一标识符，用于查询任务信息和结果 |
| workspaceId | String | 可选 | 工作空间标识符，用于获取工作空间配置 |
| resultPath | String | 可选 | 结果集文件路径，直接指定结果文件位置 |

#### 2.1.2 URL 格式

**最小化格式（仅必备参数）**
```
/result-view?taskId=xxx
```

**标准格式（推荐）**
```
/result-view?taskId=xxx&workspaceId=xxx
```

**完整格式（性能最优）**
```
/result-view?taskId=xxx&workspaceId=xxx&resultPath=xxx
```

### 2.2 参数处理逻辑

#### 2.2.1 参数验证
1. **taskId 验证**
   - 必须提供，否则返回错误提示
   - 验证 taskId 格式是否合法

2. **workspaceId 处理**
   - 可选参数，不提供时使用默认值
   - 用于获取工作空间配置

3. **resultPath 处理**
   - 优先使用 resultPath（如果提供）
   - 未提供时通过 taskId 查询获取

#### 2.2.2 数据获取流程

```
1. 解析 URL 参数
   ↓
2. 验证 taskId 是否存在
   ↓
3. 判断是否提供 resultPath
   ├─ 是 → 直接打开结果文件
   └─ 否 → 通过 taskId 查询任务信息
           ↓
           获取 resultPath
           ↓
           打开结果文件
   ↓
4. 敏感数据检查
   ↓
5. 渲染表格数据
```

### 2.4 错误处理设计

#### 2.4.1 错误场景

| 错误场景 | 错误码 | 提示信息 |
|----------|--------|----------|
| taskId 未提供 | 40001 | 缺少必要参数 taskId |
| taskId 不存在 | 40002 | 任务不存在或已被删除 |
| 任务执行失败 | 40003 | 任务执行失败，无法获取结果 |
| 结果文件不存在 | 40004 | 结果文件不存在 |
| 无权限访问 | 40005 | 无权限访问该结果 |
| 网络请求失败 | 40006 | 网络请求失败，请稍后重试 |

#### 2.4.2 错误展示方式
- 使用 Modal 弹窗展示错误信息
- 提供错误原因和建议操作
- 支持关闭弹窗

### 2.6 数据流设计

#### 2.6.1 数据获取流程
```
URL 参数解析
    ↓
参数验证
    ↓
获取任务信息（通过 taskId）
    ↓
获取结果路径（resultPath）
    ↓
敏感数据检查
    ↓
获取结果数据
    ↓
渲染表格
```

#### 2.6.2 组件通信
```
resultView.vue (父组件)
    ↓ props
result.vue (子组件)
    ↓ events
resultView.vue (父组件)
```

### 2.7 性能优化

#### 2.7.1 优化策略
1. **优先使用 resultPath**
   - 如果 URL 提供了 resultPath，直接打开结果文件
   - 避免通过 taskId 查询的额外请求

2. **数据缓存**
   - 复用现有的 IndexedDB 缓存机制
   - 减少重复请求

3. **懒加载**
   - 按需加载 result 组件
   - 减少初始加载时间

#### 2.7.2 加载状态
- 显示加载动画
- 提供加载进度提示

### 2.8 兼容性设计

#### 2.8.1 向后兼容
- 不修改现有 result.vue 组件
- 不影响 script.vue 的现有功能
- 保持现有 API 接口不变

#### 2.8.2 浏览器兼容
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 使用 Vue 2.x 兼容语法
